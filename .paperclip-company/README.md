# Lumaestro Agent Company

Bem-vindo à **Lumaestro**, a empresa de agentes que opera o Sistema Operacional Cognitivo (COS) e orquestrador Graph-RAG definitivo.

## Como Operamos

A Lumaestro utiliza uma arquitetura de orquestração **Swarm** baseada no protocolo ACP (Agent Control Protocol). Nosso fluxo de trabalho garante soberania, segurança e profundidade semântica em cada ação.

### Organograma de Elite

| Agente | Título | Reporta a | Especialidade |
| :--- | :--- | :--- | :--- |
| **Sinfonia Maestro** | CEO | (Ninguém) | Visão e Orquestração |
| **Graph Navigator** | Arquiteto de Grafos | Maestro | Graph-RAG & Semântica |
| **Core Engineer** | Engenheiro ACP | Maestro | Go, Wails & Terminal |
| **Neural Judge** | Validador Lógico | Maestro | Segurança & Auditoria |
| **Knowledge Librarian** | Bibliotecário | Maestro | Documentação & Contexto |

## Como Importar

Para trazer este enxame para o seu Paperclip:

1. Abra o terminal.
2. Navegue até a raiz do projeto Paperclip.
3. Execute:
   ```bash
   pnpm paperclipai company import --from c:\git\IA\Lumaestro\.paperclip-company
   ```
